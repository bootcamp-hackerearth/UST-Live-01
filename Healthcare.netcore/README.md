//HealthCareAxis Sprint 5

## Project Overview

HealthCareAxis is a healthcare management application developed using ASP.NET Core, Angular, and Blazor. The application enables efficient healthcare operations through secure user management, caching, event-driven communication, centralized logging, cloud deployment, and automated CI/CD pipelines.

---

## Technology Stack

### Frontend
- Angular
- Blazor WebAssembly

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server

### Messaging
- RabbitMQ

### Caching
- Redis Cache

### Logging & Monitoring
- Serilog
- Elasticsearch
- Kibana

### DevOps & Cloud
- GitHub
- Jenkins
- AWS Elastic Beanstalk
- Amazon S3

## Setup Instructions

### Clone Repository
git clone https://github.com/vyshnavipati/HealthCareAxis-Sprint5.git

### Restore Packages
dotnet restore

### Build Solution
dotnet build

### Run Backend API
dotnet run --project Healthcare.netcore

### Run Angular Application
cd HealthAxis.UI
npm install
npm start


### Run Blazor Admin Application
dotnet run --project AdminWebApp

## RabbitMQ Integration

RabbitMQ is used for implementing asynchronous communication between services and supporting event-driven architecture.

### Benefits

- Loose coupling between services
- Improved scalability
- Reliable message processing
- Better system performance

---

## Redis Cache Integration

Redis Cache is used to reduce database load and improve response times.

### Benefits

- Faster API responses
- Reduced database calls
- Improved application performance
- Better user experience

---

## Elasticsearch & Kibana

Elasticsearch is used to store and index logs generated by the application.

Kibana is used for:

- Log visualization
- Monitoring application behavior
- Troubleshooting issues
- Searching application logs

---

## CI/CD Pipeline

Jenkins is used to automate the deployment process.

### Pipeline Stages

1. Source Code Checkout
2. Angular Build
3. Blazor Publish
4. API Publish
5. Package Generation
6. Upload Package to S3
7. Deploy Application to AWS Elastic Beanstalk

### Benefits

- Faster deployments
- Reduced manual effort
- Consistent delivery process
- Improved release quality
